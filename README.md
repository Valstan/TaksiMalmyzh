общей базой и несколькими дверями. Корень — `позвони.вмалмыже.рф`, внутри него сервисы со

только домен заведут в панели хостера.

## Как запустить

```bash
npm ci
npm run dev
```

Откроется `http://localhost:3000` — корень матрёшки, весь «ПОЗВОНИ». Чтобы увидеть лицо
конкретного сервиса, откройте его поддомен на `localhost`: `http://такси.localhost:3000`
(браузер сам резолвит `*.localhost` в 127.0.0.1, править hosts-файл не нужно). Список
доменов — [`lib/sites.ts`](lib/sites.ts).

Карта и адресный справочник лежат в репозитории готовыми — сеть для запуска не нужна.

Пересобрать их (нужен Python 3.10+, примерно раз в год — за 12 месяцев в границе города
меняется 9 объектов из 3 151):

```bash
npm run map:extract && npm run map:assets && npm run data:addresses
```

База данных для разработки заводится одной командой (PostgreSQL должен быть установлен):

```bash
npm run db:setup
```

Скрипт идемпотентен: создаёт роль и базу проекта, отзывает у `PUBLIC` право `CONNECT` —
на машине разработчика один сервер обслуживает несколько репозиториев, и роль одного
проекта не должна ходить в базу другого, — и кладёт строку подключения в `.env.local`.
Пароль генерируется и в репозиторий не попадает. Ранним спринтам база не нужна: персональных
данных в них нет, а справочники — файлы.

Выкатка на прод — [`docs/DEPLOY.md`](docs/DEPLOY.md). Сайт выкачен **открыто** — решение
владельца 2026-08-29; следствия для этапов записаны в
[`docs/GO_LIVE_CHECKLIST.md`](docs/GO_LIVE_CHECKLIST.md).

Карта и поиск работают на собственных данных: страница не делает **ни одного** запроса
за пределы своего домена. Это проверяется замером, а не обещанием, — см.
[`docs/PROBE_MAPS_PROVIDER.md`](docs/PROBE_MAPS_PROVIDER.md) §6. Лицензии перенесённых
данных и шрифтов — [`public/map/LICENSES.md`](public/map/LICENSES.md).

## О чём проект

Справочник услуг города, который запускается **не как агрегатор**:

- телефоны такси, ИП, магазинов и бригад с ценами — звонок в одно касание;
- у такси-категории — модуль безопасности: пассажир включает поездку → приложение трекает
  маршрут как **подстраховку** («найти пропавшего»), явно, псевдонимно, без скрытой слежки;
- отметки и рейтинги: «дозвонился / не ответил», «цена не соответствует», звёзды.

Справочник набирает аудиторию с первого дня → бизнесы приходят за карточками, вызовами с
автоадресом и отзывами → двусторонний маркетплейс с монетизацией через видимость.

## Фазы

- **Ф1** — справочник + безопасность поездок (MVP, ядро роста)
- **Ф2** — кабинеты бизнесов: карточки, вызовы, рейтинги (предложение)
- **Ф3** — маркетплейс / монетизация (выделение, featured-листинги)
