## О чём проект

Приложение для координации работы такси, которое запускается **не как агрегатор**, а как **клиентское приложение безопасности поездок**:

- пассажир садится в такси, включает поездку → приложение трекает маршрут (откуда, куда, время, гео-трасса);
- назначение — **подстраховка**: если человек/такси «пропал», по гео-следу можно восстановить, куда он поехал, и помочь найти;
- трекинг **явный, инициированный пользователем, анонимный, без скрытой слежки**.

Через безопасность (односторонняя польза для пассажира) набираем аудиторию → затем подтягиваются таксопарки → двусторонний маркетплейс такси с монетизацией через конкуренцию фирм за показы. Классический bootstrap two-sided-маркетплейса.

## Фазы

- **Ф1** — клиентская безопасность поездок (MVP, ядро роста)
- **Ф2** — онбординг таксопарков (предложение)
- **Ф3** — маркетплейс / монетизация (аукцион показов)
