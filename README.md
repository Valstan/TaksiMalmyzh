# TaksiMalmyzh

**Мобильное приложение безопасности поездок → маркетплейс такси** (г. Малмыж).

Прод-домен (план): **такси.вмалмыже.рф**

> **Статус: спринт 1 — фундамент без персональных данных.**
> Открывается страница с картой Малмыжа и поиском адреса. Записи поездок, базы данных
> и прода ещё нет; персональных данных не обрабатывается никаких. Решения по платформе
> (PWA, гео только foreground), картам и дизайну приватности приняты — см.
> [`docs/PROJECT_STATE.md`](docs/PROJECT_STATE.md) и [`docs/SPRINT_PLAN.md`](docs/SPRINT_PLAN.md).

## Как запустить

```bash
npm ci
npm run dev
```

Откроется `http://localhost:3000`. Карта и адресный справочник лежат в репозитории
готовыми — сеть для запуска не нужна.

Пересобрать их (нужен Python 3.10+, примерно раз в год — за 12 месяцев в границе города
меняется 9 объектов из 3 151):

```bash
npm run map:extract && npm run map:assets && npm run data:addresses
```

Стенд намеренно не открыт наружу: логи веб-сервера с IP посетителей — это уже чужие
персональные данные, а значит этап B ([`docs/GO_LIVE_CHECKLIST.md`](docs/GO_LIVE_CHECKLIST.md)).

Карта и поиск работают на собственных данных: страница не делает **ни одного** запроса
за пределы своего домена. Это проверяется замером, а не обещанием, — см.
[`docs/PROBE_MAPS_PROVIDER.md`](docs/PROBE_MAPS_PROVIDER.md) §6. Лицензии перенесённых
данных и шрифтов — [`public/map/LICENSES.md`](public/map/LICENSES.md).

## О чём проект

Приложение для координации работы такси, которое запускается **не как агрегатор**, а как **клиентское приложение безопасности поездок**:

- пассажир садится в такси, включает поездку → приложение трекает маршрут (откуда, куда, время, гео-трасса);
- назначение — **подстраховка**: если человек/такси «пропал», по гео-следу можно восстановить, куда он поехал, и помочь найти;
- трекинг **явный, инициированный пользователем, анонимный, без скрытой слежки**.

Через безопасность (односторонняя польза для пассажира) набираем аудиторию → затем подтягиваются таксопарки → двусторонний маркетплейс такси с монетизацией через конкуренцию фирм за показы. Классический bootstrap two-sided-маркетплейса.

## Фазы

- **Ф1** — клиентская безопасность поездок (MVP, ядро роста)
- **Ф2** — онбординг таксопарков (предложение)
- **Ф3** — маркетплейс / монетизация (аукцион показов)
