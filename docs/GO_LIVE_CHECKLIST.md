# Go-live чек-лист (M1 / первый публичный выкат)

Пункты, обязательные к моменту первого выката. Источники: решения владельца и мандаты
brain (письма `from-brain` 2026-07-26 … 2026-08-23). Чек-лист живой — пополняется по
мере новых решений; вычёркивать пункты можно только с фактом-подтверждением.

## Гейты (без них не выкатываемся)

- [ ] **Ретеншн гео-точек** — политика принята письменно ([M0.A](PRIVACY_GEODATA_DESIGN.md)),
      реализована и **доказуемо работает**: возраст самой старой партиции ≤ срока хранения
      проверяется ежедневно, процедура удаления пишет журнал, отсутствие записи за 25 часов —
      алерт. Критерий выката — не расчёт, а показанная работа расписания.
      ⚠️ Обоснование сменилось: ёмкость гейтом **не** является при выполнении четырёх условий
      (устойчивое состояние ≈ 31 МБ, замеры в M0.A §4). Гейт — закон (ст. 5 ч. 7 152-ФЗ:
      хранить вечно нельзя) и приватность.
- [ ] **Глубина резервных копий согласована со сроком хранения**: копии таблицы сырых точек
      живут не дольше 30 суток. Иначе обещание пользователю ложно, а ст. 21 ч. 4 нарушена
      (M0.A §4.3).
- [ ] **Замеры, которые можно сделать только на живых поездках**: расход батареи, доля ложных
      срабатываний «мёртвой руки», сквозная точность прорежённой трассы, порог поворота.
      Пороги N₁/N₂ назначены по замеру, а не из кресла (M0.A §5.3, §2.5).
- [ ] **Основание обработки данных водителя** получено или риск принят письменно — трасса
      поездки есть маршрут водителя за смену (M0.A §7.1.1).
- [ ] **Уведомление РКН** о намерении обрабатывать ПДн подано **до** начала обработки
      (ст. 22 152-ФЗ). Срок хранения согласован в трёх местах: согласие, Политика обработки,
      уведомление — расхождение само по себе нарушение.
- [ ] **Политика обработки ПДн** опубликована в открытом доступе и описывает **реальные**
      процессы. Назначен ответственный, составлен акт оценки вреда (степень — высокая).
- [ ] **Локализация** (ст. 18 ч. 5) — БД физически в РФ, письменное подтверждение локации
      ЦОД получено. Проверены каналы незаметной утечки за границу: пуши (без координат в
      теле), крашлоги, аналитика, карты/геокодинг, бэкапы, CDN.
- [ ] **Согласия** — два отдельных (запись трассы / передача доверенному контакту), каждое
      отдельным документом, галочки не предустановлены, отзыв не сложнее дачи. Факт согласия
      логируется неизменяемо (бремя доказывания на нас, аккаунта нет).
- [ ] **Доверенный контакт уведомлён** по ст. 18 ч. 3: его имя и телефон — ПДн другого
      человека, полученные не от него. Уведомление уходит до начала обработки, факт логируется.
- [ ] **Секреты вне репозитория** (#008) — ключи только в env на сервере;
      secret-scan в PR-гейте стоит и принят мутационно (#114): показан красный на
      подсадном токене нужного класса (#170). Ключ шифрования трасс — **вне БД**.
- [ ] **Серверная authz реально включена** (#015): в Payload коллекции поездок и точек по
      умолчанию deny **всем, включая админов**; доступ оператора пишется в неизменяемый журнал.
- [ ] **CI-гейт** — `ci.yml` (lint, typecheck, build) на `pull_request` появляется
      вместе с первым кодом; сборка только в CI, на сервере не собирать (G20).
- [ ] **Offsite-бэкап ПДн** (#075) — заведён до появления первых пользователей.
      Ротация бэкапов согласована с ретеншном: бэкап живёт 12 месяцев — трасса живёт 12 месяцев.
- [ ] **Регламент инцидента** написан заранее: уведомление РКН в течение 24 часов, результаты
      расследования — 72 часа, те же сроки для ГосСОПКА. Шаблоны, назначенное лицо, доступ в
      личный кабинет — до go-live, не в момент утечки.
