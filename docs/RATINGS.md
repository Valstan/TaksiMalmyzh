# Рейтинги — спринт 9 (Фаза 2)

Построено 2026-09-03 по решению владельца «давай спринт 9» — **до** правового контура
(спринт 7), который план называл условием. Поэтому сделано не «как в плане», а с
ограничениями, которые снимают названные риски (оценки поимённых людей = персональные
данные, клевета, войны конкурентов) без юриста:

| Риск | Что сделано |
|---|---|
| Текст отзыва = клевета, модерация, ответ бизнеса | **Текста нет.** Только звёзды 1–5. Пункт 4 плана (модерация, право ответить) не нужен: нечего модерировать |
| Народное досье на физлиц | Работников заводит **сам бизнес** в кабинете; посетители работников не создают. Убрать работника может бизнес — имя со страницы уходит, голоса остаются в общем рейтинге |
| Единички конкурентов | Один голос на устройство в день на бизнес и отдельно на работника (первичный ключ, HMAC-псевдоним устройства как у краудсигналов); повтор перезаписывает свой голос |
| Рейтинг у того, кто о нём не знает | Оценивать можно **только карточку с владельцем** (кабинет, спринт 8). Нет кабинета — нет рейтинга |
| Правовая основа (§9.2) | Остаётся открытой до спринта 7; имена работников — данные, которые вводит их работодатель, и это надо отразить в текстах согласия спринта 7 |

## Что видит посетитель

На карточке бизнеса с владельцем: «★ 4,6 (12)» — среднее по всем голосам за год (фирме и
работникам; формула владельца «звёзды Васи и Коли суммируются в общий рейтинг»), список
работников с их звёздами, и виджет: выбрать «фирму» или работника, нажать звезду.

## Что видит бизнес

В кабинете у карточки: рейтинг и число голосов, список работников с их средними, поле
«добавить работника» (до 30), «убрать».

## Что хранится

`market.worker` (`entry_id`, `name`, `active`), `market.rating` (`entry_id`, `worker_id` —
0 для фирмы, `device_ref`, `day`, `stars`), PK `(entry_id, worker_id, device_ref, day)`.
Окно и срок — 365 дней (`pruneRatings` в часовом тике). Миграция `20260903_180000_ratings`,
DDL `lib/market-ddl.ts`, код `lib/ratings.ts`, роут `/api/rate`, действия
`worker_add`/`worker_remove` в `/api/cabinet`, `components/{RateWidget,CabinetWorkers}.tsx`.
